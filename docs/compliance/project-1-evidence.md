# Project 1 — YouTube API Compliance Evidence

## Required evidence

### 1. Privacy Policy screenshots
Capture screenshots of `/privacy.html` showing, at minimum:
- YouTube Data API / YouTube API Services disclosure
- YouTube API Services Terms / Developer Policies links
- Google Privacy Policy link
- Google Security Settings / authorization revocation link
- YouTube API data deletion and account deletion process
- Cookie/storage disclosure
- Privacy contact

### 2. Homepage screenshot
Capture the public homepage `/` showing, in the same frame where practical:
- StatAxis identity and product purpose
- The **YouTube Data API** disclosure section
- Privacy Policy and Terms & Conditions links
- YouTube branding/text
- Footer Privacy Policy link

The homepage must remain publicly accessible without login.

### 3. Terms of Service documentation
Use the public `/terms.html` page or export it as PDF for submission. It includes:
- YouTube Terms of Service acceptance
- YouTube API Services reference
- Third-party/API terms
- Acceptable-use rules
- Data/IP provisions
- Privacy reference
- Contact and governing-law provisions

## Conditional evidence

### OAuth flow — NOT CURRENTLY APPLICABLE
Repository review found no OAuth implementation or OAuth scope configuration. Do not submit fabricated OAuth screenshots. If OAuth is added later, capture the Google consent screen, exact scopes, and revocation flow.

### Upload interface — NOT APPLICABLE
StatAxis does not provide a YouTube video-upload/account-management workflow. Do not submit upload screenshots.

### Player/embed — NOT APPLICABLE
StatAxis does not use a YouTube player/embed workflow as its core use case. Do not submit player/embed screenshots unless that feature is added.

### Dashboard / analytics — APPLICABLE
Capture a dashboard/feature screenshot showing StatAxis analytics/reporting functionality, preferably with YouTube/digital-video metrics visible. The screenshot should show the StatAxis product context and not expose credentials, API keys, secrets, or private user data.
