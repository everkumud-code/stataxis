STATAXIS USER GUIDE

How to use StatAxis

StatAxis turns observed digital audience movement into a clear intelligence workspace: Data → Analysis → StatAxis View. Use the dashboard to see movement, compare channels, evaluate a video and understand the signal.

The public dashboard shows demonstration values only. Create or open a profile to access your workspace and live data.

01 · Open your profile

1
Choose Open Profile or Sign in from the dashboard.
2
Create an account with your email and password, or sign in to an existing account.
3
Once authenticated, the dashboard changes from Preview to your StatAxis workspace.

02 · Evaluate

1
Paste a public YouTube URL into Evaluate a YouTube URL.
2
Give the evaluation a custom display name so you can recognize it later.
3
Select Evaluate Signal. StatAxis presents the available observation, STX Index, confidence and interpretation.

03 · Understand the dashboard

Audience

Shows the observed audience/performance level available to StatAxis for the selected view.

Momentum

Shows the direction and pace of recent movement rather than only the accumulated total.

Competitive Position

Places the selected channel in the current StatAxis comparison and shows movement where historical evidence exists.

Historical Comparison

Use Today, 3 Weeks, 1 Month and 1 Year to understand change against the available historical record.

04 · Understand STX Index™

STX Index™ is StatAxis's composite intelligence indicator. It condenses the available measured signals into a 0–100 score so movement can be read quickly.

The score should be read together with Confidence, the available signals and the Signal Drivers. A score is not a substitute for the underlying data.

DATA

What the observed record shows.

ANALYSIS

Why the observed movement matters in context.

STATAXIS VIEW

The concise interpretation supported by the available evidence.

StatAxis does not turn a correlation into a claimed cause. Where evidence is incomplete, the workspace should say so.

06 · Live Audience Monitor

Authenticated users can work with a live YouTube URL, give it a display name, and view the audience window. The dashboard groups observations into Hindi, English, Regional and Unknown language markets when that information is available.

Use the time window to inspect current and peak concurrent audience and the channel-level timeline.

07 · StatAxis methodology

StatAxis preserves timestamped observations and builds intelligence from the record that is actually available. Historical views are based on persisted observations; missing history is not silently invented.

STX Index combines multiple measured dimensions into a single readable indicator. Confidence reflects how much of the intended signal set is available for the current observation. Signal Drivers show which measured components contribute to the current score.

StatAxis View separates measured facts from interpretation and avoids unsupported causal claims. The product is designed to make the number explainable rather than asking the user to accept a number without context.

Source data, collection availability and the applicable upstream terms can limit what StatAxis can observe. The dashboard should always be read with those boundaries in mind.
